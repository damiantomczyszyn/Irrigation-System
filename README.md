# Weather-Station & Watering-Manager

## NodeMCU based on ESP8266 Weather Station
The weather station provides readings of parameters such as temperature, pressure, humidity, and current precipitation. <br>

## NodeMCU based on ESP8266 Weathering Manager
The watering manager is responsible for turning on and off the appropriate sprinklers. The system uses the web weather api and sensor status readings from the local weather station to make an intelligent decision using a decision tree whether it is the right time to turn on watering.
